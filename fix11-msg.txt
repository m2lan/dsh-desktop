fix: navigate main window to harness instead of a control panel

The app previously opened a control panel as the main window, confusing
users who expected the harness directly. Now:

- the main window shows a minimal splash (progress/errors) only
- kernel boots in Rust; on first launch it auto-installs if missing
- once the URL is known, Rust navigates the main window to the harness
- check-upstream now uses `npm view` instead of a raw fetch (fixes the
  "registry returned 406" error)
